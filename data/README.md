# داده‌های زمان‌بندی مترو تبریز — خط ۱

منبع: دو پوستر رسمی سازمان حمل و نقل ریلی شهرداری تبریز
(`زمانبندی مهر ماه1404 (1).pdf` برای روزهای عادی و `جمعه و تعطیلی.pdf` برای جمعه‌ها و تعطیلات رسمی).

فایل اصلی: [`tabriz-metro-line1-schedules.json`](./tabriz-metro-line1-schedules.json)

## ساختار

- `stations` — ۱۸ ایستگاه به ترتیب مسیر. `index: 0` = ائل گؤلی (سر خط جنوبی)، `index: 17` = نور (سر خط شمالی).
  ایستگاه `salar-melli` با پرچم `"isHub": true` علامت‌گذاری شده (قطب در پوستر).
- `directions` — دو جهت مسیر با شناسه‌های `eyl-goli-to-noor` و `noor-to-eyl-goli`.
- `schedules` — دو برنامه:
  - `weekday` → روزهای عادی (شنبه تا پنجشنبه) — بروزرسانی ۱۴۰۴/۰۶/۳۱ — فاصله حرکت ۱۵ دقیقه
  - `holiday` → جمعه‌ها و تعطیلات رسمی — بروزرسانی ۱۴۰۴/۰۳/۱۷ — فاصله حرکت ۱۶ دقیقه

### خواندن زمان‌ها

```
schedules.<type>.directions.<direction>.trips[i][s]
```

`trips[i]` آرایه‌ای ۱۸ عضوی است که عضو `s` آن **زمان حضور قطار iام در ایستگاه با `index == s`** است:

- در جهت `eyl-goli-to-noor` زمان‌ها صعودی‌اند (عضو ۰ = لحظه حرکت از ائل گؤلی، عضو ۱۷ = لحظه رسیدن به نور).
- در جهت `noor-to-eyl-goli` زمان‌ها نزولی‌اند (عضو ۱۷ = لحظه حرکت از نور، عضو ۰ = لحظه رسیدن به ائل گؤلی).

نمونه — «قطار بعدی از ایستگاه X به سمت نور»:

```js
const now = minutesSinceMidnight();
const next = schedule.directions["eyl-goli-to-noor"].trips
  .map(t => t[stationIndex])
  .find(t => toMinutes(t) >= now);
```

## خلاصه داده‌ها

| برنامه | جهت | تعداد قطار | اولین حرکت | آخرین حرکت |
|---|---|---|---|---|
| روزهای عادی | ائل گؤلی → نور | ۶۰ | ۰۵:۵۵ | ۲۰:۴۰ |
| روزهای عادی | نور → ائل گؤلی | ۶۱ | ۰۶:۱۵ | ۲۱:۱۵ |
| جمعه/تعطیل | ائل گؤلی → نور | ۴۹ | ۰۷:۳۰ | ۲۰:۱۸ |
| جمعه/تعطیل | نور → ائل گؤلی | ۵۰ | ۰۷:۴۰ | ۲۰:۴۴ |

مدت سفر کامل مسیر: ۳۵ دقیقه. اختلاف زمانی ایستگاه‌های متوالی ۲ دقیقه است (بین «میدان ساعت» و ایستگاه بعدی ۳ دقیقه).
